Projects

Red is Bad

Challenging puzzle-platformer with retro 1-bit art where each door leads to a new area. The doors aren’t interconnected—stay sharp! Red means danger, so be careful. The goal: find the key to unlock the great door and face the fearsome final boss.

Tech: Unity (C#). Platforms: PC/HTML5.

Toon Shooter

Wave-based top-down shooter with in-game shop (weapons & upgrades), data-driven weapon stats, object-pooled projectiles, modular enemy archetypes, and a scalable wave director (intensity, budgets, miniboss flags).

Tech: Godot (GDScript). Platforms: PC/HTML5.

Coffee Burger

Idle tycoon/management game for mobile. Persistent resource system (save/load), scalable upgrades for cashiers and products (coffee/burger), hiring system to add cashiers, offline income with caps, and responsive mobile UI.

Tech: Godot (GDScript). Platform: Android.

Leap Day

Mobile vertical platformer inspired by LeapNight. Emphasis on precise, responsive movement, touch controls, accurate collisions, camera smoothing with look-ahead, and checkpoint system. Optimized draw calls and collision shapes for mobile.

Tech: Godot (GDScript). Platform: Android.

Pulpix

2D top-down survival shooter focused on physics-driven interactions. Destructible/Pushable props, projectile & explosion forces, procedural wave spawns, AI with LOS and obstacle handling, particles/VFX, and camera shake.

Tech: Godot (GDScript). Platforms: PC/HTML5.

Flappy Plane

Custom Flappy Bird-style arcade made in Godot (GDScript). Features a stable gameplay loop, procedural pipe generation, precise collisions, parallax background and a responsive UI. Input is decoupled for keyboard/touch.

Tech: Godot (GDScript). Platforms: PC/HTML5.

Cannon Soccer

Physics puzzle built in C++ (CMake) with SFML + Box2D. Fire ragdolls from a cannon to knock balls into the goal. From-scratch systems: sprite animation, particle effects, transitions, interactive music, and a lightweight game-state framework.

Tech: C++17, SFML, Box2D. Platforms: Windows/Linux.

Asteroids

A faithful remake of the classic Atari game—graphics, proportions, and feel—implemented via vector math. Single "Arcade" mode: chase high scores as difficulty ramps up.

Built in C++ and OpenGL (GLUT). Traditional OOD with modular single-purpose systems.

Astropulse

NES-style shoot 'em up. Visuals and mechanics are limited to what the console could do. Based on the zodiac: 12 levels with new mechanics each, and a boss at the end representing each sign.

Built fully in C++ with SFML, using a hybrid design between OOD and ECS.

Geowars

Arcade game inspired by Geometry Wars. Built to implement an ECS (Entity–Component–System) architecture. Minimalist look—no sprites, everything rendered via SFML shapes.

Tech: C++ and SFML.

Pong!

The classic Pong with Arkanoid-like features: size power-ups and extra rebound elements. Includes PvP and PvPC with three difficulty levels.

Early experiment made before learning OOP—everything lives in a single script. Messy code but includes procedural music and other fun bits.

ASCII Frogger

A console-based remake of Atari's Frogger with three difficulty levels. Created as an integrative assignment for the "Introduction to Programming" course.

Pure C++ with ASCII graphics rendered directly in the terminal.
